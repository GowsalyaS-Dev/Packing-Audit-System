# Packing Audit Management System

An automated packing verification system for validating packing data and streamlining quality control processes.

### Key Modules
- Packing Data Validation
- SAP CSV Data Processing
- Invoice and Item Verification
- Duplicate and Failed Record Detection
- Packing Requirement Verification
- Audit Report Generation

### Tech Stack
C# | .NET Worker Service | Microsoft SQL Server | HTML | CSS | JavaScript

### Key Contributions
- Developed automated packing audit and validation workflows.
- Processed SAP-exported CSV data and handled invalid or duplicate records.
- Implemented database operations using Microsoft SQL Server.
- Generated packing audit reports for verification and quality control.
